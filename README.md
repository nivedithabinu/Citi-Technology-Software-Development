This repository contains my work completed as part of Citi's Technology Software Development Job Simulation Program hosted on Forage.

The program simulated real-world software development tasks and helped me gain practical exposure to various workflows, system design, debugging, and project documentation.

Following are the tasks completed:

1) Task One - Create a State Diagram for Loan Management System

2) Task Two - Create a feature proposal on the role of Credit Risk Assessment in Machine Learning and what can be done to make the model more efficient

3) Task Three - Build a Java Application that queries live stock data from Yahoo Finance every 5 seconds and stores the result along with timestamp in a queue

4) Task Four - Creating a line graph of the stock prices

This experience helped me understand how software development projects are handled in real-world environments. It also strengthened my technical, analytical, and documentation skills while improving my confidence in using development tools and workflows.
